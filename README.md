# Nimbu's Pocket Dimensions (NeoForge)

Welcome to Nimbu's Pocket Dimensions, a mod that allows one to make customisable pocket dimensions that can be accessed anywhere.

This repository is a **NeoForge 1.21.1** port of the original Fabric mod.

- Original (Fabric): https://github.com/NimbuMC/Nimbus-Pocket-Dimensions  
- This fork: https://github.com/Aaalice233/Nimbus-Pocket-Dimensions  

Find the official mod page at Nimbu's Pocket Dimensions on [Modrinth](https://modrinth.com/mod/nimbus-pocket-dimensions) or [Curseforge](https://www.curseforge.com/minecraft/mc-mods/nimbus-pocket-dimensions).

## Build

```powershell
.\gradlew.bat build
```

Output jar: `build/libs/pocketdimensions-<version>.jar`

## Dev runs

```powershell
.\gradlew.bat runClient
.\gradlew.bat runServer
```
